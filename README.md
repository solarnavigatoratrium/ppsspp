# PPSSPP

### PlayStation Portable emulator for PC and mobile

PPSSPP is the best PSP emulator available, running PSP games at high definition on PC, Android, iOS, and macOS. Enjoy classics like God of War and Persona with improved graphics and stable performance.

<br>

---

## Features

| | |
|:---|:---|
| **High-Definition** | Render PSP games at 2× to 10× the original resolution |
| **Wide Platform Support** | Windows, macOS, Linux, Android, and iOS all supported |
| **Save State Support** | Save and load anywhere in any game for convenience |
| **Controller Compatible** | Full gamepad support including PlayStation and Xbox controllers |
